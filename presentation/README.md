본 프레젠테이션 스위트는 **2026년 9월 3일 수노의 다운로드 정책 개편(일반 다운로드 공급 97% 급감)과 10월 유튜브의 AI 음악 규제 강화 팩트**를 바탕으로, 수강생들에게 압도적인 시장 기회를 증명하고 **픽미 수강생 독점 무제한 무손실 다운로더**를 선물하는 실전 발표용 덱입니다.

## 🎯 2가지 전용 발표 덱 구성

```
presentation/
├── index.html       # 🚀 프레젠테이션 셀렉터 허브 (단축키 1: 프리, 2: 프로)
├── free.html        # 🎁 [덱 1] 프리 버전 발표 덱 (수노 9.3 쇼크 분석 & 수강생 무제한 선물)
├── free.js          #     └── 프리 버전 전용 슬라이드 제어 & 가상 소음 차단 시연
├── pro.html         # ⚡ [덱 2] 프로 버전 발표 덱 (기능 설명 위주 & 인터랙티브 데모)
├── pro.js           #     └── 프로 버전 전용 A/B 청음 데크 & 속도 레이스 시연
├── style.css        # 🎨 공통 사이버 다크 글래스모피즘 16:9 반응형 대형 폰트 스타일
└── run.sh           # 🖥️ 로컬 전용 서버 실행 스크립트 (Port: 8085)
```

## 🎮 발표자 전용 조작 단축키

| 키 / 조작 | 동작 설명 |
| :--- | :--- |
| **`Space`**, **`→`**, **`PageDown`** | 다음 슬라이드로 이동 |
| **`←`**, **`PageUp`** | 이전 슬라이드로 이동 |
| **`F`** | 16:9 프로젝터 맞춤 **전체화면(Fullscreen)** 토글 |
| **`N`** | 발표 현장에서 슬라이드별 진행 시간 및 멘트를 확인할 수 있는 **발표자 큐시트(Speaker Notes)** 서랍 열기/닫기 |
| **`ESC`** | 10장 슬라이드를 한눈에 보고 원하는 곳으로 즉시 이동하는 **오버뷰 네비게이터** |
| **`1` / `2`** | 허브 화면(`index.html`)에서 1번 누르면 프리 덱, 2번 누르면 프로 덱으로 즉시 이동 |
