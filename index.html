Core Capabilities

스튜디오 마스터링 급 오디오 캡처 기술

일반적인 사운드카드 스테레오 믹스 녹음의 한계를 완전히 극복한 순수 W3C Web Audio 파이프라인 격리 기술을 탑재했습니다.

🛡️

100% 사운드 분리 격리

유튜브, 디스코드, 컴퓨터 카톡 알림음, 게임 소리가 1%도 녹음 파일에 들어가지 않습니다. 오직 Suno 플레이어 내부 오디오 그래프에만 직접 연결되어 순수 원음만 추출합니다.

W3C AudioContext Zero Noise Cross-App Isolation
💎

16-bit WAV & 320k MP3

PCM 원시 버퍼를 무손실 16-bit 44.1kHz WAV로 즉시 빌드하거나, LameJS 코어 엔진을 통해 320kbps 최고음질 MP3로 실시간 듀얼 채널 인코딩하여 스튜디오 퀄리티를 유지합니다.

16-bit Linear PCM 320kbps MP3 LameJS Engine
🔄

0:00초 완벽 자동 동기화

WAV 또는 MP3 버튼을 누르면 플레이어가 스스로 곡의 0:00초로 자동 이동하여 재생을 시작하고, 곡이 끝나는 순간 파일 저장이 자동으로 완료됩니다.

Auto Seek 0:00 Auto End Trigger Zero Click Hassle
🎯

동일 제목 생성 쌍 완벽 분리

Suno가 프롬프트마다 2곡씩 생성하여 제목이 똑같은 최신 상위 2곡에 대해서도, 고유 UUID 및 재생 시간 대조 알고리즘으로 다른 곡이 재생되는 오류를 100% 원천 차단했습니다.

UUID ClipID Matching Duration Differentiator Top-2 Pair Safety
🎛️

제목 바로 옆 원클릭 다운로드

Suno 곡 목록 행과 하단 고정 플레이어 바의 곡 제목 바로 오른쪽에 깔끔한 인라인 버튼이 밀착 배치되어, 번거로운 다운로드 팝업 없이 원클릭으로 바로 다운로드가 시작됩니다.

Inlined Row Buttons Player Bar Dock Zero Duplication

Easy Setup

1분 만에 끝나는 초간단 설치법

네이버 웨일 및 구글 크롬 브라우저에서 확장 프로그램 압축을 해제하고 바로 등록하여 사용하실 수 있습니다.

1

확장 프로그램 폴더 준비

확장 프로그램 소스 폴더를 컴퓨터에 준비합니다.

2

웨일 확장앱 관리자 열기

웨일 브라우저 주소창에 아래 주소를 입력하여 확장앱 관리자 페이지로 이동합니다.

whale://extensions
3

[개발자 모드] 및 [압축해제 설치]

우측 상단의 [개발자 모드] 토글을 켠 뒤, 상단에 나타나는 [압축해제 된 확장앱 설치]를 누르고 압축을 푼 폴더를 선택합니다.

4

Suno 웹에서 바로 사용

suno.com 탭을 새로고침(F5)하면 곡 제목 옆과 플레이어 바에 [WAV] [MP3] 버튼이 생성됩니다.

1

확장 프로그램 폴더 준비

확장 프로그램 소스 폴더를 컴퓨터에 준비합니다.

2

크롬 확장 프로그램 관리자 열기

크롬 주소창에 아래 주소를 입력하여 확장 프로그램 페이지로 이동합니다.

chrome://extensions
3

개발자 모드 & 폴더 로드

우측 상단 [개발자 모드]를 활성화하고 좌측 상단 [압축해제된 확장 프로그램을 로드합니다]를 클릭하여 폴더를 지정합니다.

4

설치 완료

이제 suno.com에 접속하면 원클릭 무손실 WAV 및 320k MP3 캡처 버튼이 완벽하게 작동합니다!
