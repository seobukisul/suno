# 🎙️ Suno Pure Audio Studio Capture - Interactive Web Portfolio

Suno AI 전용 100% 사운드 격리 무손실 WAV & 320k MP3 캡처 확장 프로그램의 **공식 인터랙티브 포트폴리오 웹사이트**입니다.

---

## 🌟 핵심 구성 및 인터랙티브 기능

1. **마우스 휠 반응 인터랙션 (Scroll-Driven Interactions)**:
   - **상단 스크롤 게이지 (Scroll Progress Bar)**: 휠 스크롤 진행도에 맞춰 최상단 네온 그라데이션 바가 실시간 확장됩니다.
   - **헤더 글래스모피즘 트랜지션**: 스크롤 다운 시 상단 네비게이션이 60px로 슬림해지며 20px 블러 백드롭 필터가 활성화됩니다.
   - **스크롤 리빌 3D 모션**: 마우스 휠로 화면을 내릴 때마다 기능 카드, 비교 테이블, 파이프라인 단계들이 부드럽게 3D Y축 회전과 페이드인으로 등장합니다.

2. **마우스 호버 모션 액션 (Hover Motion Actions)**:
   - **3D Card Tilt 액션**: 카드 위에 마우스 커서를 올리면 커서 좌표(X, Y)에 반응하여 입체적으로 카드가 기울어집니다 (`perspective: 1000px`).
   - **스포트라이트 글로우 팔로워**: 마우스 위치를 실시간 추적하여 카드 표면에 에메랄드 원형 빛이 따라다닙니다.
   - **마그네틱 버튼 풀 (Magnetic Motion)**: CTA 버튼 및 다운로드 버튼 주변에 마우스가 다가가면 버튼이 자석처럼 커서 쪽으로 살짝 끌려옵니다.

3. **라이브 인터랙티브 시뮬레이터 (Web Audio Live Engine)**:
   - 실제 Suno 화면과 동일한 곡 목록 및 플레이어 바를 브라우저 내에서 직접 조작할 수 있습니다.
   - **[🌊 WAV]** 또는 **[🎵 MP3]** 버튼을 누르면 Web Audio API 신디사이저가 실제 Lo-Fi 칠 음악을 실시간 재생합니다.
   - 우측 하단에 **실시간 14밴드 이퀄라이저 VU 메터 HUD**가 떠오르며 실제 사운드 주파수에 맞춰 춤추듯 반응합니다.
   - `[⏹️ 여기까지 다운로드]`를 누르면 실시간으로 16-bit WAV 데모 파일이 즉시 브라우저로 다운로드됩니다.
   - `[🔇 스피커 소리 끄기]` 토글을 켜면 귀에는 아무 소리도 안 들리지만 VU 메터는 계속 뛰는 '조용히 캡처' 모드를 직접 체감할 수 있습니다.

4. **공식 GitHub 배포 연동 및 단계별 설치 안내**:
   - 공식 GitHub 저장소(`https://github.com/seobukisul/suno`) 연동 및 최신 소스코드 배포.
   - 네이버 웨일 및 구글 크롬 전용 단계별 확장 프로그램 설치 가이드 제공.

## 🚀 로컬 실행 방법

포트폴리오 웹사이트는 이미 백그라운드 서버로 구동 중입니다:

- **웹사이트 주소**: [http://localhost:8089](http://localhost:8089)
- **실행 스크립트**: `./run.sh` 또는 `python3 server.py`
